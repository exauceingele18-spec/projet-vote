# Plateforme de Vote Électronique Sécurisée

Projet réalisé dans le cadre du cours de Sécurité et Réseaux (Master 1).
**Groupe 28**

## 🚀 Fonctionnalités
- Authentification sécurisée par JWT.
- Hachage robuste des mots de passe (Argon2 / Bcrypt).
- Mécanisme anti-brute-force intégré.
- Validation stricte des données avec Pydantic et FastAPI.
